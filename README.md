# learnToLearn
[上瘾式学习 · 纠偏打卡]是一个学习工具，把多种高效学习法整合成可执行的学习闭环。
1. 学习计划 + 自动拆解
输入计划（名称/科目/总时长/开始日/每日任务数/子主题），引擎自动套用学习方法拆解：每个子主题 → 1–2 个/天、5–20 分钟的微任务，并绑定五步流程与间隔复习。
一键载入预设的「系规冲刺」计划（10-14~10-24：前 5 天理论第4–17章、接着 4 篇论文各 2 小时、收尾复盘）。
2. 每日固定五步流程（今日页）
按你给定的标准流程执行，每步可勾选：

任务微拆 → 2. 输入（禁抄书/划线）→ 3. 主动回忆（写盲区）→ 4. 交叉练习 → 5. 一分钟费曼复盘
主动回忆下可记录卡壳盲区，复盘下可写费曼口述。
「完成学习」按钮可一键把五步标记为完成，并自动生成复习计划。
3. 迷你番茄计时器
5/10/15/20 分钟可选，环形倒计时，到点提醒——靠频次而非时长形成上瘾。

4. 间隔复习引擎（复习页）
学完当天起算，第 2 / 7 / 30 天自动提醒回看，只展示盲区，不从头重学。

5. 学习方法纠偏
今日页常驻反模式警报（通读/抄写/狂划线/熬夜）。
完成学习有门控：未走主动回忆无法"假学会"完成。
6. 打卡 + 连续天数
每日打卡，顶部显示🔥连续天数；连续打卡是后续奖励的触发条件。

7. 奖励机制
里程碑路线图（统计页）：连续 1/3/7/14/21/30 天对应大奖励（水果→饮品→游戏→购物→电影→大餐）。
随机奖励池：今日页「🎲 抽奖励」随机抽一个（羽毛球/公路车/听歌/散步…），抽到按天保存。
奖励池管理：可手动增、删、改奖励项，实时持久化。
8. 统计 + 成就墙
连续/累计打卡天数、微任务完成数、间隔复习完成数，及 8 个解锁式成就（小成就驱动多巴胺）。

9. 方法参考页
内置《上瘾式学习》《费曼》《迷你番茄》《间隔复习》《主动回忆+交叉练习》说明，以及固定流程与辅助小规则。
